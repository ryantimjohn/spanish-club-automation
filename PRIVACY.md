# Privacy policy: Spanish Club Page Poster

Spanish Club Page Poster is the Meta app that Spanish Club for Socialists, a free Spanish conversation club in Washington, DC, uses to post its weekly event post to its own Facebook Page. It runs from the code in this repository (`post.py`).

- It only posts to the club's own Facebook Page and reads that Page's details in order to post.
- It doesn't use Facebook Login, and it doesn't collect, store or share anyone's personal data.
- The post log in this repository (`log/posted.json`) holds only post IDs, links and times.

## Data deletion
The app keeps no personal data, so there's nothing to delete. To ask a question or have a post removed, open an issue in this repository.
